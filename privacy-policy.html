プライバシーポリシー

最終更新日：2026年9月1日

本プライバシーポリシーは、パズルゲーム「ずらしけし」（以下「本アプリ」）における利用者データの取り扱いについて定めたものです。

1. 本アプリが端末内に保存する情報

本アプリは、次の情報をお使いの端末内にのみ保存します。氏名・メールアドレスなど、個人を特定できる情報の入力を求めることはありません。

  • 難易度ごとのベストスコアとプレイ結果の記録
  • 音量・BGMなどの設定
  • 広告の表示間隔を管理するための回数と最終表示時刻

これらは外部のサーバーへ送信されません。アプリをアンインストールすると削除されます。

2. 広告の配信について

本アプリは、Google が提供する広告配信サービス「Google AdMob」を利用して広告を表示します。広告の配信のため、Google Mobile Ads SDK が次の情報を自動的に取得し、Google と共有します。

  • IPアドレス（広告配信・分析・不正行為の防止のため）
  • アプリの操作に関する情報および診断情報（広告配信・分析・不正行為の防止のため）
  • 広告 ID（Android の広告 ID・App set ID。広告配信および分析のため）

これらの情報の取り扱いについては、Google のプライバシーポリシー（https://policies.google.com/privacy）および「Google のサービスを使用するパートナーによるデータ使用」（https://policies.google.com/technologies/partner-sites）をご確認ください。

3. 広告のパーソナライズと同意

本アプリは、欧州経済領域などの対象地域において、広告に関する同意の取得画面を表示します。同意の内容は、アプリ内の設定画面からいつでも変更できます。

また、Android 端末の「設定」から広告 ID をリセットまたは削除することで、広告のパーソナライズを制限できます。

4. 通信について

本アプリの通信は広告の読み込みと同意管理のためにのみ行われます。ゲームそのものはオフラインで遊べます。

5. アプリ内購入について

本アプリにアプリ内購入はありません。決済情報を取り扱うことはありません。

6. お子様の利用について

本アプリは、児童を主な対象としたアプリではありません。児童から意図的に個人情報を収集することはありません。
